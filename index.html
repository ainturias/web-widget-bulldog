Características

¿Por qué LYRA IA?

Un widget plug-and-play que transforma cualquier sitio en un asistente inteligente.

🚀

Integración instantánea

Un solo <script> y una etiqueta HTML. Sin dependencias, sin configuración compleja.

🎨

Totalmente personalizable

Ajusta colores, nombre del bot y mensaje de bienvenida directamente desde los atributos HTML.

⚡

Carga diferida (defer)

El script se carga de forma diferida para no bloquear el renderizado ni afectar el rendimiento.

🔒

Seguro y confiable

Conexión directa a la API de LYRA con comunicación segura sobre HTTPS en todo momento.

💬

Respuestas en tiempo real

El asistente responde de forma fluida y natural, sin recargar la página del cliente.

📱

Responsive por defecto

Funciona perfectamente en escritorio, tablet y móvil sin configuración adicional.

Implementación

El código que ves funcionando

Estas dos líneas son todo lo que necesitas pegar en el HTML del cliente.

index.html HTML 
<!-- 1. Cargar Script del Chatbot de LYRA IA -->
<script src="https://telobuscoya.lyra-agent.tech/widgets/chatbot.js" defer></script>

<!-- 2. Ubicar la etiqueta donde deseas visualizar el Chatbot -->
<custom-chatbot
  api-url="https://telobuscoya.lyra-agent.tech"
  bot-name="Lyra Assistant"
  color-primary="#7c3aed"
  welcome-message="¡Hola! 👋 Soy **Lyra**, tu asistente virtual premium."
></custom-chatbot>
